## 第 3 章 核心框架：EventBus、GameModel、GameConfig（对应方案 Day 3 上午）

### 3.1 本章要写的脚本

#### 3.1.1 `Scripts/Core/EventBus.cs`（单例 + 观察者模式落点）

```csharp
// EventBus: 全局唯一事件总线（观察者模式落点）。承担所有跨层通信，
// 保证 Controller→Model→View 数据流单向。挂 DontDestroyOnLoad。
public class EventBus : MonoBehaviour
{
    public static EventBus Instance { get; private set; }
    private readonly Dictionary<Type, Delegate> _handlers = new Dictionary<Type, Delegate>();

    void Awake()          // 唯一性校验：重复实例销毁
    public void Post<T>(T evt)                    // 发布事件
    public void Subscribe<T>(Action<T> handler)   // 订阅
    public void Unsubscribe<T>(Action<T> handler) // 退订（View 必须在 OnDisable 调用）
}
```

#### 3.1.2 事件定义 `Scripts/Core/GameEvents.cs`

全部 `readonly struct`，字段只读。标准事件清单（本章先定义全部，后续章节逐步使用）：

| 事件 | 类型 | 载荷 | 触发时机 |
|---|---|---|---|
| `PhaseChangedEvent` | 状态广播 | `GamePhase Phase` | 每次状态机切换 |
| `DepthChangedEvent` | 数据变更 | `int Depth` | 钩子 Y 变化（节流后） |
| `FishCaughtEvent` | 玩法触发 | `FishDef Def` | 捕获一条鱼 |
| `CatchCountChangedEvent` | 数据变更 | `int Current, int Capacity` | 捕获计数变化 |
| `SkillCountChangedEvent` | 数据变更 | `int Left, int Total` | 技能消耗 |
| `RoundEndEvent` | 玩法触发 | `RunResult Result` | 回到水面 |
| `ResetCommand` | 玩家指令 | 无 | 结算面板点"继续体验" |
| `SkillRequestCommand` | 玩家指令 | 无 | 点击技能按钮 |
| `PauseCommand` / `ResumeCommand` | 玩家指令 | 无 | 暂停菜单 |

`GamePhase` 枚举：`Tutorial / Countdown / Descending / Ascending / Settlement`。

#### 3.1.3 `Scripts/Models/GameModel.cs`（纯 C#，M 层红线）

```csharp
// GameModel: 唯一数据真源（Model 层）。纯 C# 类，禁止引用任何 MonoBehaviour。
public class GameModel
{
    public int Depth { get; }              // 当前深度（写时经 EventBus 广播 DepthChangedEvent）
    public int MaxDepthReached { get; }    // 本局最深
    public int SkillLeft { get; }          // 剩余技能次数
    public int Coin / Shell { get; }       // 本局货币累计
    public Dictionary<FishDef, int> CatchDict { get; }  // 捕获统计（结算遍历用）
    public bool IsFull { get; }            // 捕获数 ≥ CatchCapacity
    public void AddCatch(FishDef def)      // 捕获自增 + 广播
    public void UseSkill()                 // 技能次数 -1 + 广播
    public void Reset()                    // ★ 单局重置唯一入口（红线 7）
}
```

**红线**：`Reset()` 内部清空捕获字典、重置深度、技能次数、货币累计标志；**禁止**在多个 State/Controller 里散落重置代码。

### 4.1 本章要写的脚本

#### 4.1.1 `Scripts/Core/GameStateMachine.cs` + `Scripts/Core/GameState.cs`

```csharp
// GameState: 状态基类。抽象 OnEnter/OnUpdate/OnExit，状态内逻辑写在状态类里。
public abstract class GameState
{
    public abstract void OnEnter();
    public abstract void OnUpdate(float dt);
    public abstract void OnExit();
    // 状态能收到的事件回调（由状态机转发）：
    public virtual void OnHookHitFish(FishController fish) { }  // 同一事件在不同状态语义不同（核心例证）
}

// GameStateMachine: 状态机驱动器，每帧调用 Current.OnUpdate()。
public class GameStateMachine
{
    public GameState Current { get; private set; }
    public void SwitchTo(GameState next)   // OnExit → 换引用 → OnEnter → Post<PhaseChangedEvent>
    public void Tick(float dt)             // 每帧调 Current.OnUpdate
    public void HandleHookHitFish(FishController fish)  // 转发给 Current
}
```

#### 4.1.2 五个状态类（`Scripts/Controllers/States/`，本章先写空壳）

| 文件 | 职责一句话 | 进入下一态条件 |
|---|---|---|
| `TutorialState.cs` | 三步教学模态（首局出现，PlayerPrefs 标记） | 玩家过完三步点"知道了" |
| `CountdownState.cs` | 3-2-1 大字，禁用玩法输入，HUD 重置 | 倒计时播完（约 3 秒） |
| `DescendingState.cs` | 钩 6m/s 下坠，玩家左右拖动避鱼 | 触碰鱼（该鱼被捕获）或深度达 100m |
| `AscendingState.cs` | 6m/s 收线主动撞鱼，满 10 切 24m/s | 深度回到 0m |
| `SettlementState.cs` | 弹结算面板等待玩家选择 | "继续体验"→Countdown；"退出"→结束 |

本章重点实现 `CountdownState`：协程/计时器 3→2→1→GO，倒计时结束 `SwitchTo(descending)`。其余四态只写 `Debug.Log` 占位。
